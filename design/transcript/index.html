1 · The run row

Tile (16 pt, the kind that best says what the run did), a sentence in 13-pt secondary, meta in 11-pt tertiary, a chevron when there is something to expand. A run of one is the call itself and opens with one click. See 01-run.md.

Settled

Live — the outline of the tile is the only thing that moves

Tiles, shown at 2× — Lamé squircle n = 4, the sidebar's family. States change the tile, never the row.

2 · The command document

A page, not a terminal: what was meant (the description), what ran (the command card, a leading cd … && set quiet), what came out (numbered, findable). The status line carries only facts that are true. The SDK sends no output while a command runs, so nothing pretends to stream it. See 02-command.md.

3 · File documents

Xcode's source editor, read-only. Edits are small, so the diff is unified and in place; the characters that changed get the wash twice. New files get no wash. Reads get the file map. See 03-file.md.

4 · Background news

A task notification is work, not conversation: it takes the run row's grammar. Click opens what the task produced; ↖ goes back to the call that started it. See 04-background.md.

5 · Local commands, dividers, interruptions

What you did to the CLI rather than said to the model. /exit and /compact are 77 % of slash commands and both mark a boundary, so they become one. See 05-local.md.

6 · Other voices

Messages' group chat: the other party on the leading side, named above a grey bubble, with the sidebar's glyph for who they are. See 06-voices.md.

7 · Tools that talk to you

Questions and plans are addressed to the reader, so they break out of the run. Task-list calls stay in it. See 07-talk.md.
